## README for Check-in 3 Folder



## Files

1. **enrich.py** — deduplicates tracks across both users, queries MusicBrainz for release year + genre tags, caches results to `track_metadata.csv`. Covers top-played tracks until ~90% of listening time is accounted for (due to long run time). Rate-limited to 1 req/sec per MusicBrainz ToS.
2. **similarity.py** — per-category sub-scores (24-hour listening cosine, 12-month seasonality cosine, artist Jaccard, genre cosine, release-year cosine) → composite score. Validated by same-user split-halves vs cross-user.
3. **classification.py** — Decision Tree + one other technique for "would user like this song."
4. **clustering.py** — tests user separability.
5. **outlier.py** — per-track features (play_count, total/avg ms, skip/shuffle rate, hour mean+std, release year) → IsolationForest per user, plus a complementary genre-rarity pass (primary genre <1% of listening time). Writes `outliers_{user}.csv` and prints top-10 with z-score explanations.

# BONUSES
1. **../recommender.py** — Content-based recommender at the repo root. Builds a taste profile per user, then runs two modes: (a) **cross-user** — score tracks from the other user's library that the target hasn't played, by cosine similarity to the target's taste profile; (b) **discovery** — within a user's own library, surface tracks played only once that match their broader taste. Caps at 2 tracks per artist for diversity. Writes `recs_cross_{a}_to_{b}.csv` and `recs_discovery_{user}.csv` into this folder. Run from the repo root: `python recommender.py`.
2. **../dashboard.py** — Streamlit dashboard at the repo root. Loads Vanessa + Darelle as baselines and accepts one or more additional Spotify CSVs via the sidebar uploader (each file = a new user, auto-named from its filename). All uploaded users appear in every comparison view (Overview, Similarity, Clustering, Outliers). Run from the repo root: `streamlit run dashboard.py`
